# Project Description

This project covers two Proofs of Concept (PoC):

1. **Appointment Scheduling via WhatsApp**
A system is implemented that allows scheduling appointments via WhatsApp, integrating a chatbot to interact with the user.

2. **Appointment Notification**
A functionality is developed to notify the user about the scheduled appointment.

## Credentials Configuration

To run the project, it is essential to have the necessary credentials. The `credentials.json` file must be generated by following the instructions detailed in the following links:

- [Facebook Developers](https://developers.facebook.com/apps/)
- [Google Cloud Console](https://console.cloud.google.com/)

Make sure to complete these steps to correctly configure the integration for both scheduling and hook execution.
